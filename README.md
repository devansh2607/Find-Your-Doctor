# Find Your Doctor

Machine learning-powered healthcare recommendation system that predicts suitable medical specialists based on patient symptoms.

## Live Demo
https://find-your-doctor.onrender.com

## Project Overview

Find Your Doctor helps users identify the most appropriate medical specialist based on symptoms entered through a web interface. The system uses a trained Random Forest machine learning model to generate recommendations and helps users locate nearby specialists.

## Features

- Predicts suitable medical specialists from symptoms
- Machine Learning-based recommendation engine
- Nearby doctor search functionality
- User-friendly web interface
- End-to-end healthcare recommendation workflow

## Tech Stack

- Python
- Flask
- Scikit-Learn
- Random Forest
- Bootstrap
- HTML/CSS

## Machine Learning Workflow

1. Collect symptom data
2. Preprocess and clean data
3. Train Random Forest model
4. Generate specialist predictions
5. Display recommendations to users
